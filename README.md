# Jarvis 1.0

> A privacy-first local AI desktop assistant.

---

## 📖 Vision

Jarvis is an intelligent desktop assistant that runs locally on your computer. It helps automate daily tasks, answer questions, and control your PC using natural language while keeping your data private and secure.

---

## 🎯 Goals

- Local AI using Ollama
- Desktop automation
- Browser automation
- File and folder management
- AI memory
- Voice commands (Future)
- Secure permission system
- Undo support
- Modular architecture

---

## 🛠️ Technology Stack

### Frontend

### Backend

- Ollama
